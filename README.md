# 내 주변 헬스장 랭킹

지정한 위치·반경 안의 헬스장을 네이버 지도 리뷰 사진으로 분석해 기구 투자 수준 순위를 보여주는 정적 페이지입니다.

- 지도 핀 드래그와 반경 슬라이더(0.5~3km)로 범위를 정하고, 분석 요청 문구를 복사해 Claude에서 분석합니다.
- 분석 결과는 `data/result.json`, 브랜드 점수는 `data/brands.json`에서 읽습니다.
- 선호 브랜드를 체크하면 가산점(×1.5, 초안)을 적용한 순위를, 리셋하면 기본 순위를 보여줍니다.

현재 `data/result.json`은 가상 샘플 데이터입니다.

## 실행
GitHub Pages(Settings → Pages → main 브랜치 루트)로 배포합니다. 로컬에서는 `python3 -m http.server`로 열어야 JSON을 불러옵니다.
